## 4. Decision Tree — подбор параметров

### Что такое Decision Tree (дерево решений)

Дерево решений — это алгоритм, который строит цепочку вопросов-условий:

```
alcohol > 13.5?
├── Да → flavanoids > 2.8? → ...
└── Нет → proline < 600? → ...
```

Каждый вопрос делит данные на две части. На конце ветки — предсказание класса.

### GridSearchCV — три параметра одновременно

```python
param_grid_dt = {
    'max_depth':    list(range(1, 15)),
    'criterion':    ['gini', 'entropy'],
    'max_features': [None, 'sqrt', 'log2']
}
```

Итого: 14 × 2 × 3 = **84 комбинации** × 5 фолдов = 420 обучений. GridSearchCV пробует все и выбирает лучшую.

**`max_depth`** — максимальная глубина дерева:
- Маленькая (1-2) → недообучение, слишком простые правила.
- Очень большая → дерево заучивает обучающие данные, переобучение.
- Нужно найти золотую середину.

**`criterion`** — чем измерять "нечистоту" узла при выборе разбиения:
- `'gini'` — индекс Джини (по умолчанию). Вычисляется быстрее.
- `'entropy'` — информационный выигрыш (энтропия). Математически чище.
- На практике дают схожий результат; GridSearchCV сам выберет лучшее.

**`max_features`** — сколько признаков рассматривать в каждом узле при поиске лучшего разбиения:

| Значение | Сколько признаков | Пример (13 признаков) |
|---|---|---|
| `None` | Все признаки | 13 из 13 |
| `'sqrt'` | √n_features | √13 ≈ 3-4 |
| `'log2'` | log₂(n_features) | log₂(13) ≈ 3 |

> **Зачем ограничивать?** При `None` дерево всегда найдёт лучший признак → более "жадное" дерево, склонное к переобучению.
> `'sqrt'` и `'log2'` добавляют случайность — дерево рассматривает только подмножество признаков в каждом узле. Это снижает переобучение. Именно поэтому Random Forest по умолчанию использует `'sqrt'`.

```python
grid_dt = GridSearchCV(DecisionTreeClassifier(random_state=42), param_grid_dt, cv=5, scoring='accuracy')
grid_dt.fit(X_train, y_train)

print(f"Лучшие параметры: {grid_dt.best_params_}")
```

**Как работает GridSearchCV:**
1. Берёт каждую из 84 комбинаций параметров.
2. Делит `X_train` на 5 фолдов, обучает и проверяет 5 раз.
3. Усредняет точность.
4. Выбирает комбинацию с наилучшим средним результатом.

```python
dt = grid_dt.best_estimator_  # лучшая уже обученная модель
dt_pred = dt.predict(X_test)
```

`best_estimator_` — GridSearchCV сам переобучил победившую комбинацию на всём `X_train`.

## 6. Почему gini высокий в корне и стремится к 0 на листьях

### Индекс Джини (Gini Impurity)

Формула: `Gini = 1 - Σ(pᵢ²)`

где `pᵢ` — доля класса i в узле.

**Пример — корневой узел** (все 142 обучающих примера, три класса примерно поровну):
- class_0: 47/142 ≈ 0.33, class_1: 57/142 ≈ 0.40, class_2: 38/142 ≈ 0.27
- Gini = 1 − (0.33² + 0.40² + 0.27²) = 1 − (0.109 + 0.160 + 0.073) = **≈ 0.66**

Высокое значение — узел "грязный", три класса перемешаны.

**Пример — чистый лист** (все 38 примеров — только class_2):
- class_2: 38/38 = 1.0, остальные = 0
- Gini = 1 − (0² + 0² + 1²) = 1 − 1 = **0.0**

Нулевое значение — узел "чистый", один класс.

**Вывод:** Gini = 0 означает идеальное разделение. Дерево при каждом разбиении выбирает признак и порог, которые **максимально снижают** Gini — это и есть критерий качества разбиения.

### Энтропия (Entropy)

Формула: `Entropy = -Σ(pᵢ · log₂(pᵢ))`

- Максимум при равном распределении классов (в корне).
- Минимум (0) при чистом узле (на листе).

**Разница между gini и entropy:**
- Gini немного быстрее вычисляется.
- Entropy чуть сильнее штрафует "почти чистые, но не совсем" узлы.
- На практике разница в точности минимальная — GridSearchCV выберет лучшее.

  - Пример: реальных класс 0 было 14 → нашла 12 → Recall = 0.86
- **F1-score** — среднее гармоническое Precision и Recall. Один итоговый показатель.
- **Support** — сколько образцов этого класса в тест-выборке.

## 8. ROC-кривая и оптимальный порог

### Зачем нужна ROC при multiclass?

У нас 3 класса, а ROC строится для бинарных задач. Поэтому используем подход **One-vs-Rest (OvR)**: отдельно строим ROC для каждого класса (класс X vs все остальные).

```python
y_test_bin = label_binarize(y_test, classes=[0, 1, 2])
```

Превращает `[0, 1, 2, 1, 0, ...]` в матрицу:
```
[[1, 0, 0],   # это класс 0
 [0, 1, 0],   # это класс 1
 [0, 0, 1],   # это класс 2
 ...]
```

```python
y_score_dt = dt.predict_proba(X_test)
```

- `predict_proba()` возвращает вероятности для каждого класса.
- Пример: `[0.8, 0.1, 0.1]` — модель на 80% уверена, что это класс 0.

```python
for i in range(3):
    fpr, tpr, _ = roc_curve(y_test_bin[:, i], y_score_dt[:, i])
    roc_auc = auc(fpr, tpr)
    plt.plot(fpr, tpr, label=f'Класс {i} (AUC = {roc_auc:.2f})')
```

- `fpr` (False Positive Rate) — доля ложных срабатываний.
- `tpr` (True Positive Rate = Recall) — доля правильно найденных.
- **AUC** (площадь под кривой) — чем ближе к 1.0, тем лучше модель. 0.5 = случайное угадывание.

```python
plt.plot([0, 1], [0, 1], 'k--')  # пунктирная линия = случайная модель (AUC=0.5)
```

### Оптимальный порог (метод Юдена)

```python
for i in range(3):
    fpr, tpr, thresholds = roc_curve(y_test_bin[:, i], y_score_dt[:, i])
    j_scores = tpr - fpr          # Индекс Юдена = TPR - FPR
    best_idx = np.argmax(j_scores) # Где максимум — там лучший порог
    print(f"Класс {i}: порог = {thresholds[best_idx]:.2f}")
```

**Зачем менять порог?**
По умолчанию модель предсказывает класс если вероятность > 0.5. Но иногда оптимально поставить порог 0.3 или 0.7.

**Метод Юдена:** ищем порог где `TPR - FPR` максимален — т.е. модель много угадывает правильных и мало ошибается. Это геометрически точка на ROC-кривой, ближайшая к верхнему левому углу.

## 9. Random Forest — подбор числа деревьев

### Что такое Random Forest (случайный лес)

Случайный лес — это ансамбль из многих деревьев решений:

1. Берёт случайную подвыборку данных (с возвращением — bootstrap).
2. Строит дерево, используя только случайное подмножество признаков в каждом разбиении.
3. Повторяет N раз (N = `n_estimators`).
4. Итоговое предсказание — **голосование**: какой класс назвало большинство деревьев.

**Почему это лучше одного дерева:**
- Каждое дерево видит разные данные → разные ошибки.
- Усредняя много "немного разных" деревьев, мы уменьшаем разброс (variance).
- Одно дерево легко переобучается; лес — намного устойчивее.

### GridSearchCV для RF

```python
param_grid_rf = {'n_estimators': [10, 20, 50, 100, 150, 200]}

grid_rf = GridSearchCV(RandomForestClassifier(random_state=42), param_grid_rf, cv=5, scoring='accuracy')
grid_rf.fit(X_train, y_train)
```

Логика та же, что для дерева — перебираем число деревьев, выбираем лучшее по CV.

> Обычно точность растёт до ~100 деревьев и дальше почти не меняется, только замедляется обучение.

```python
rf = grid_rf.best_estimator_  # лучшая RF-модель
rf_pred = rf.predict(X_test)
```

## 12. Precision vs Recall

**Precision (точность)** — "когда говоришь X, ты прав?"
- Формула: `TP / (TP + FP)`
- Ложноположительная ошибка (FP): сказал "класс 0", а это класс 1.

**Recall (полнота)** — "всех ли X ты нашёл?"
- Формула: `TP / (TP + FN)`
- Ложноотрицательная ошибка (FN): не распознал класс 0, назвал его классом 1.

**Для классификации вин важнее Precision**, потому что:
- Неправильно определить сорт вина = неверная маркировка продукта.
- Это прямая ошибка в продукте (юридическая, коммерческая).
- Лучше иногда сказать "не уверен" (низкий Recall), чем уверенно ошибиться (низкий Precision).

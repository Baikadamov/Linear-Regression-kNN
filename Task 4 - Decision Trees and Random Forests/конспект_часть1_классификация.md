## 5. Decision Tree — Дерево решений

### Что такое дерево решений?
Дерево задаёт последовательность вопросов типа «alcohol > 13.5?», и в зависимости от ответа идёт влево или вправо. Каждый **лист** дерева — это предсказанный класс.

### Базовая модель
```python
dt_base = DecisionTreeClassifier(random_state=42)
dt_base.fit(X_train, y_train)
```
Без ограничений дерево растёт до максимальной глубины и **переобучается** (на train — 100%, на test — хуже).

```python
print(f'Train accuracy: {dt_base.score(X_train, y_train):.4f}')  # 1.0 — переобучение!
print(f'Test accuracy:  {accuracy_score(y_test, y_pred_base):.4f}')  # 0.9444
```
**Переобучение (overfitting)** = модель выучила весь train наизусть, но плохо обобщает на новые данные.

### Подбор глубины через кросс-валидацию
```python
depths = range(1, 16)
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

for depth in depths:
    dt = DecisionTreeClassifier(max_depth=depth, random_state=42)
    scores = cross_val_score(dt, X_train, y_train, cv=skf, scoring='accuracy')
    cv_scores_dt.append(scores.mean())
```
**Как работает кросс-валидация:**
1. Train делится на 5 равных частей (фолдов)
2. Модель обучается на 4 частях, тестируется на 1-й
3. Повторяем 5 раз, меняя тестовую часть
4. Берём среднее — это надёжная оценка качества

`StratifiedKFold` гарантирует, что в каждом фолде пропорция классов одинакова.

```python
best_depth_dt = depths[np.argmax(cv_scores_dt)]
```
`np.argmax` — находит индекс максимального значения, то есть лучшую глубину.

### Pruning (подрезка дерева)
```python
for ms in min_splits:
    for ml in min_leafs:
        dt = DecisionTreeClassifier(
            max_depth=best_depth_dt,
            min_samples_split=ms,   # минимум образцов для разбиения узла
            min_samples_leaf=ml,    # минимум образцов в листе
            ...
        )
```
- `min_samples_split` — узел разбивается только если в нём не меньше N образцов
- `min_samples_leaf` — лист должен содержать не меньше N образцов

Это **ограничивает** рост дерева и борется с переобучением.

### Финальная модель и визуализация
```python
plot_tree(dt_final, feature_names=wine.feature_names,
          class_names=list(wine.target_names), filled=True, ...)
```
Рисует схему дерева: каждый узел показывает признак, порог, количество образцов и класс.

## 7. Random Forest — Случайный лес

### Идея
Random Forest — это **N деревьев**, каждое обучается на случайной подвыборке данных (bagging) и случайном подмножестве признаков. Итоговое предсказание = голосование большинства деревьев.

**Почему это лучше?** Деревья делают разные ошибки, и их ошибки компенсируют друг друга.

### Подбор n_estimators
```python
n_estimators_list = [50, 100, 200, 300, 500]
for n_est in n_estimators_list:
    rf = RandomForestClassifier(n_estimators=n_est, random_state=42)
    scores = cross_val_score(rf, X_train, y_train, cv=skf, scoring='accuracy')
```
`n_estimators` — количество деревьев в лесу. Больше = стабильнее, но медленнее. После ~100 прирост незначительный.

### Подбор max_depth
```python
depths_rf = list(range(1, 16)) + [None]
```
`None` означает без ограничения глубины — дерево растёт пока не разделит все образцы. Для леса это часто оптимально, т.к. деревья регуляризуют друг друга.

## 8. ROC-кривая (AUC-ROC)

> Показывает, насколько хорошо модель **ранжирует** образцы по вероятности.

### Почему OvR (One-vs-Rest)?
При **мультиклассе** нельзя просто построить одну ROC — строим отдельную для каждого класса: «class_0 vs всё остальное», «class_1 vs всё остальное» и т.д.

```python
y_test_bin = label_binarize(y_test, classes=[0, 1, 2])
```
Превращает `[0, 2, 1, ...]` в матрицу:
```
[[1, 0, 0],
 [0, 0, 1],
 [0, 1, 0], ...]
```

```python
for i in range(n_classes):
    fpr_i, tpr_i, _ = roc_curve(y_test_bin[:, i], y_prob_dt[:, i])
    auc_i = auc(fpr_i, tpr_i)
```
- `fpr` — False Positive Rate: из всех НЕ-class_i, сколько мы ошибочно назвали class_i
- `tpr` — True Positive Rate (Recall): из всех реальных class_i, сколько мы нашли
- `AUC` — площадь под кривой. AUC=1.0 = идеальная модель, AUC=0.5 = случайное угадывание

### Macro-average ROC
```python
all_fpr = np.unique(np.concatenate([...]))  # объединяем все точки FPR
mean_tpr = np.zeros_like(all_fpr)
for i in range(n_classes):
    fpr_i, tpr_i, _ = roc_curve(...)
    mean_tpr += np.interp(all_fpr, fpr_i, tpr_i)  # интерполируем на общую сетку
mean_tpr /= n_classes  # усредняем
```
Усредняем все 3 ROC-кривые в одну итоговую (macro-average).

## 9. Оптимальный порог

По умолчанию класс присваивается при вероятности ≥ 0.5. Но иногда выгоднее сдвинуть порог.

```python
thresholds = np.arange(0.05, 0.96, 0.01)
for t in thresholds:
    y_pred_t = (y_scores >= t).astype(int)  # 1 если вероятность >= t, иначе 0
    precisions.append(precision_score(...))
    recalls.append(recall_score(...))
    f1s.append(f1_score(...))

best_idx = np.argmax(f1s)  # порог с максимальным F1
```

**Компромисс Precision vs Recall:**
- Высокий порог → модель осторожна → высокий Precision, низкий Recall
- Низкий порог → модель агрессивна → низкий Precision, высокий Recall
- Лучший баланс → максимальный F1-score

## Ключевые понятия

| Термин | Объяснение |
|---|---|
| **Overfitting** | Модель выучила train наизусть, плохо работает на новых данных |
| **Pruning** | Ограничение роста дерева для борьбы с overfitting |
| **Bagging** | Обучение каждого дерева на случайной подвыборке (Bootstrap AGGregatING) |
| **Cross-validation** | Оценка модели на нескольких разбиениях данных для надёжности |
| **AUC-ROC** | Метрика качества ранжирования, не зависит от порога классификации |
| **Stratify** | Сохранение пропорций классов при разбиении |
| **OvR** | One-vs-Rest — стратегия ROC для мультикласса |

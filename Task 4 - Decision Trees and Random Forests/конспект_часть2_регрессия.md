## 5. Метрики регрессии

> В регрессии мы предсказываем число, поэтому ошибка = разница между предсказанным и реальным значением.

### MAE — Mean Absolute Error
```python
mae = mean_absolute_error(y_test, y_pred)
```
Среднее абсолютное отклонение: `MAE = mean(|y_real - y_pred|)`

**Интерпретация:** «В среднем ошибаемся на X единиц.» Легко понять, устойчив к выбросам.

### MSE — Mean Squared Error
```python
mse = mean_squared_error(y_test, y_pred)
```
Среднеквадратичная ошибка: `MSE = mean((y_real - y_pred)²)`

**Интерпретация:** Штрафует большие ошибки сильнее (из-за квадрата). Единицы — квадратные, неудобно читать.

### RMSE — Root Mean Squared Error
```python
rmse = np.sqrt(mse)
```
Квадратный корень из MSE — возвращает ошибку в исходных единицах (как MAE, но больше штрафует выбросы).

### R² — Коэффициент детерминации
```python
r2 = r2_score(y_test, y_pred)
```
`R² = 1 - (MSE модели / MSE базовой модели)`

- `R² = 1.0` — модель идеальна, предсказывает точно
- `R² = 0.0` — модель не лучше чем просто предсказывать среднее
- `R² < 0` — модель хуже чем среднее (это плохо!)

**Интерпретация:** «Модель объясняет X% дисперсии (разброса) в данных.»

---

## 6. Decision Tree Regressor

### Как дерево делает регрессию?
Аналогично классификации, но в каждом **листе** — не класс, а **среднее значение** всех обучающих образцов, попавших в этот лист.

### Подбор max_depth через кросс-валидацию
```python
depths_reg = range(1, 21)
kf = KFold(n_splits=5, shuffle=True, random_state=42)

for depth in depths_reg:
    dt_reg = DecisionTreeRegressor(max_depth=depth, random_state=42)
    scores = cross_val_score(dt_reg, X_train_h, y_train_h, cv=kf, scoring='r2')
    cv_scores_dt_reg.append(scores.mean())

best_depth_dt_reg = list(depths_reg)[np.argmax(cv_scores_dt_reg)]
```
- Проверяем глубины от 1 до 20
- Оцениваем по R² (чем выше, тем лучше)
- `KFold` вместо `StratifiedKFold` — для регрессии

**Результат:** лучшая глубина = 9, CV R² ≈ 0.67

### Финальная модель и метрики
```python
dt_reg_final = DecisionTreeRegressor(max_depth=best_depth_dt_reg, random_state=42)
dt_reg_final.fit(X_train_h, y_train_h)
y_pred_dt_reg = dt_reg_final.predict(X_test_h)
```

```
Decision Tree Regressor (max_depth=9):
  MAE:  0.4357   ← ошибка в среднем $43,570
  MSE:  0.4151
  RMSE: 0.6443   ← ошибка ≈ $64,430
  R²:   0.6833   ← объясняет 68% дисперсии
```

## 7. Анализ остатков (Residuals)

> **Остатки (residuals)** = разница между реальным и предсказанным значением: `residual = y_real - y_pred`

```python
residuals_dt = y_test_h - y_pred_dt_reg

# График 1: Residuals vs Predicted
axes[0].scatter(y_pred_dt_reg, residuals_dt, alpha=0.3, ...)
axes[0].axhline(y=0, color='red', linestyle='--')  # линия нуля

# График 2: Гистограмма остатков
axes[1].hist(residuals_dt, bins=50, ...)
```

### Что ищем на этих графиках?

**Хорошая модель:**
- Точки на scatter должны быть равномерно распределены вокруг нуля (красной линии)
- Гистограмма остатков должна быть похожа на нормальное распределение (колокол по центру)

**Плохая модель:**
- Если точки «расходятся» при больших предсказаниях — гетероскедастичность
- Если есть паттерны (кривая, не хаос) — модель не улавливает нелинейности

**Наш случай:** При `y_pred ≈ 5.0` остатки только отрицательные — это из-за «обрезания» датасета на уровне $500,000.

## 8. Random Forest Regressor

### Подбор n_estimators
```python
n_est_reg_list = [50, 100, 200, 300]
for n_est in n_est_reg_list:
    rf_reg = RandomForestRegressor(n_estimators=n_est, random_state=42)
    scores = cross_val_score(rf_reg, X_train_h, y_train_h, cv=kf, scoring='r2')
    cv_scores_n_est_reg.append(scores.mean())
    print(f'n_estimators={n_est}: CV R² = {scores.mean():.4f}')
```

Результаты:
```
n_estimators=50:  CV R² = 0.8024
n_estimators=100: CV R² = 0.8045
n_estimators=200: CV R² = 0.8056  ← лучший
n_estimators=300: CV R² = 0.8055
```
После 200 деревьев прирост R² ничтожный — выбираем 200.

### Подбор max_depth
```python
depths_rf_reg = list(range(5, 21)) + [None]
```
Начинаем с 5 (не с 1) — для регрессии на 16k записях мелкие деревья точно плохи.

Результаты показывают постепенный рост R² с глубиной:
```
max_depth=5:    CV R² = 0.6655
max_depth=10:   CV R² = 0.7819
max_depth=None: CV R² = 0.8056  ← лучший
```
`None` = без ограничений. Для леса это нормально — деревья сами «регуляризуют» друг друга через голосование.

### Финальная модель
```python
rf_reg_final = RandomForestRegressor(
    n_estimators=200, max_depth=None, random_state=42
)
rf_reg_final.fit(X_train_h, y_train_h)
y_pred_rf_reg = rf_reg_final.predict(X_test_h)
```

```
Random Forest Regressor:
  MAE:  0.3268   ← $32,680 (было $43,570 у дерева)
  MSE:  0.2540
  RMSE: 0.5040   ← $50,400 (было $64,430 у дерева)
  R²:   0.8062   ← 80.6% (было 68.3% у дерева)
```
**Улучшение по всем метрикам!**

## Сравнение: Classification vs Regression деревьев

| Аспект | Классификация | Регрессия |
|---|---|---|
| **В листе** | Класс (голосование) | Среднее значение |
| **Функция потерь** | Gini impurity / Entropy | MSE |
| **Метрики** | Accuracy, F1, AUC | MAE, RMSE, R² |
| **Кросс-валидация** | StratifiedKFold | KFold |
| **Масштабирование** | Не нужно | Не нужно |

---

## Ключевые понятия

| Термин | Объяснение |
|---|---|
| **MAE** | Средняя ошибка в понятных единицах, устойчива к выбросам |
| **RMSE** | Как MAE, но сильнее штрафует большие ошибки |
| **R²** | Доля дисперсии, объяснённая моделью (0 до 1, выше = лучше) |
| **Residuals** | Остатки — разница между реальным и предсказанным |
| **Гетероскедастичность** | Когда ошибки растут при больших значениях (плохо) |
| **max_depth=None** | Дерево растёт без ограничений глубины |
| **n_estimators** | Количество деревьев в случайном лесу |
| **Bagging** | Каждое дерево обучается на случайной выборке с возвращением |

Sentiment Analysis Classification with Different Vectorizers and Models

In this assignment, you need to build a Sentiment Analysis classification model for social media text using:

Vectorizers:
* TfidfVectorizer
* CountVectorizer (Bag of Words)

Classification ML Models:
* XGBClassifier
* CatBoostClassifier

You need to perform multiclass classification on 3 sentiment labels:
* positive
* negative
* neutral

Dataset (Sentiment Analysis Dataset from Kaggle): https://www.kaggle.com/datasets/mdismielhossenabir/sentiment-analysisLinks to an external site.

Goal:
* Compare combinations of vectorizers and models;

Main tasks:
* Evaluate using: Accuracy and Weighted F1-Score;
* Build a final leaderboard;
* Select and analyze the best model.

You can use materials from machine-learning-in-nlp-bag-of-words.ipynb
